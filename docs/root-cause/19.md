# Root cause: PR #19 (named-results gate) failed eight verifier and review rounds

PR #19 set out to catch a lesson that names a theorem the site does not prove without saying so
(PR #14's math review found the strong law, Edgeworth, Berry–Esseen and joint-MGF uniqueness
used that way). The first design scanned lesson prose for result names and for marker phrases
such as "quoted without proof".

## Failed rounds

| Round | Finding | Fix attempted |
| --- | --- | --- |
| Verifier r1 | Curly-apostrophe names (Boole’s inequality, Vandermonde’s identity) escaped the scan | Fold ’ into ' |
| Verifier r2 | Titles ending "equation", "law", "rule", "formula" and accented names were not scanned | More title words |
| Reviewer 1 (c03c05ff) | The skip list hid real titles; many rows could be deleted with no failure | Lowercase titles, smaller skip lists |
| Verifier r5 | Headings without "the" were not scanned | Heading and sentence-start scans |
| Verifier r6, r7 | Title Case and text after ";" were missed, then Title Case produced bogus fragments | Case folding per title word |
| Verifier r8 | Title Case runs swallowed earlier titles; ordinary words gave false positives | Scope cut to exact registry names |
| Reviewer 1 (4f1408d4) | Marker phrases ("is assumed", "assumes the") matched ordinary hypotheses | — |

## Shared root cause

The premise was wrong: deciding from free prose which phrases name a result, and whether a
sentence says it is unproved, is natural-language understanding. Every word list, case rule and
marker phrase had a counterexample in real lesson text, so each round fixed one and exposed the
next. A prose heuristic can never be complete, so the gate could never pass a careful verifier.

## Structural fix

The lessons now say it explicitly. Each lesson lists in `results` the registry ids of the named
results it names or states, and `src/content/results.json` gives each id its name, status
(proved, quoted, background) and home lesson. `scripts/results-check.mjs` reads only those tags:
every tag is registered, every registered result is tagged somewhere (so a deleted result cannot
go unnoticed), and a proved or quoted result's home lesson tags it. Nothing is inferred from
prose. Whether a lesson's tags are complete, and whether a quoted result is presented as quoted,
is checked by the independent math review, which is told to confirm nothing named is untagged.
