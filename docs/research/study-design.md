# Study design evidence

The course alternates worked examples with problems, asks for reasoning before hints, and keeps self-ratings separate from assessed mastery. The [official study guide](https://ies.ed.gov/ncee/wwc/practiceguide/1) supports worked examples, retrieval, explanatory questions and connections between concrete and abstract representations.

[Test-enhanced learning](https://pubmed.ncbi.nlm.nih.gov/16507066/) found better delayed recall after retrieval than restudy in its prose experiments. This motivates an attempt before answer reveal. It does not establish a learning gain for this site.

[Developing simulation activities to improve statistical reasoning](https://www.tandfonline.com/doi/10.1080/10691898.1999.12131279) cautions that exploration alone need not improve reasoning. Each experiment therefore asks for a prediction and an explanation. A simulation illustrates its model and does not prove a theorem.

The layout follows [reflow guidance](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html). Charts provide [detailed alternatives](https://www.w3.org/WAI/tutorials/images/complex/), and save feedback uses [status messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html). Automated checks cover observable structure and layout; physical assistive-technology use needs separate evidence.

The bounded syllabus ends at limit theorems and includes the common discrete and continuous families, conditional independence, mixed laws, joint transformations, order statistics and Jensen's inequality. Inference, measure theory and a full stochastic-process course remain separate subjects. All explanations and problems are original.
