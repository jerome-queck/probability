# Guided topic paths and fixed recall sets

Learners can choose a topic and inspect the earlier ideas that lead to it. The lesson catalogue owns prerequisite edges and curriculum order. Planning derives their transitive closure rather than maintaining another graph. The complete problem library and chapter checkpoints remain available.

A pure reducer owns captured paths, bounded recall sets and explicit continuation. The reader holds this visit-local state above ordinary route content. The reducer receives the catalogue through its factory so direct Node behavior tests do not depend on Vite's module discovery. Existing route and progress stores keep their responsibilities.

Ratings save through the progress store and update visible badges without replacing or advancing the current problem. Closing a set records a visit-local action. It does not establish attempts, studied status or mastery. Later sets keep their captured membership so the learner can reach a distant target without changing durable marks. Refreshing from current records is explicit.

A resolved-identity boundary resets personal plans and scratch during account discovery, unavailable identity or owner changes. Saving, failed writes and conflicts for the same owner retain the active set and existing recovery controls. Account failures never fall back to guest records. Scratch and reveals survive movement within a set, but clear when leaving Practice, closing or replacing the set, or reloading.

We rejected another external store, a persistent session schema, custom route serialization and a read-and-recall task hierarchy. The reducer contains the required graph and session policy with fewer lifecycle boundaries. Movement carries the expected current lesson ID to reject stale actions. Recall panels stay mounted with stable keys and native hidden attributes. The library renders outside active recall so section IDs remain unique.

At narrow widths, the bounded Today panel precedes the full path. The initial prototype buried Start below the prerequisite list. Desktop keeps the path and next actions side by side. Verification covers rating and clearing, movement, captured continuation, history, reload, identity transitions and the complete four-width content sweep. Local identity fixtures and hosted ChatGPT sign-in remain separate claims.
